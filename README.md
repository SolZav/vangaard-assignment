# Enhancing styles with transitions

## Objective
This project focuses on understanding and demonstrating how adding transitions can improve the look and feel of a website. 

## Synopsis
This project intends to demonstrate an example of how adding different transitions and hover styles can make a website look more professional. This example is fictitious and does not represent a real company, the sole intention is to showcase my skills.

## Process
For this project I was provided with the content for the site, as well as screenshots and videos showcasing what the final product should look like. The goal of this project was to demonstrate my ability to write CSS just by looking at the finished product, and all styles were written from scratch by me.

## Results
The final site mimicked the expected result almost exactly, with the transitions being properly timed and the size transformation being accurate.
